# EduTrack Teacher Install Guide (Windows)

This guide is for teachers and school staff. No coding setup is required.

## 1) Download EduTrack

1. Open your school-provided EduTrack release link.
2. Download one installer file:
- `EduTrack_<version>_x64-setup.exe` (recommended), or
- `EduTrack_<version>_x64_en-US.msi`

## 2) Install EduTrack

1. Double-click the installer file.
2. If Windows shows a security prompt, select `Run anyway` only if the file came from your trusted school source.
3. Follow the setup wizard until installation completes.
4. Launch EduTrack from the Start Menu.

## 3) First Launch

1. Open EduTrack.
2. If Windows Firewall asks for permission, allow access.
3. Create or select your school/class in the app.
4. Start working normally (attendance, tests, reports stay on your machine).

## 4) Updating to a New Version

1. Close EduTrack.
2. Download the new installer from the latest release link.
3. Run the installer. It will update the app.
4. Reopen EduTrack.

## 5) Uninstall

1. Open `Settings > Apps` in Windows.
2. Find `EduTrack`.
3. Select `Uninstall`.

## 6) If Something Goes Wrong

- App does not open:
1. Restart your computer.
2. Try opening EduTrack again from Start Menu.

- Installer blocked:
1. Contact your school IT admin.
2. Share the installer file name and screenshot of the error.

- Need help:
1. Send your school IT admin:
- Your Windows version
- EduTrack version
- Screenshot of the message/error
